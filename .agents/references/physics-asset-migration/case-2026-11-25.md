# 实例：UEFN → ImagineGame Manny

## 已验证的范围

2026-11-25，源GameAnimationSanple的PA/PCA表现作为参考，目标ImagineGame的PA_Mannequin_PC存在明显滑动和约束/碰撞差异。完成迁移、参考姿势适配、PCA引用修正和物理配置对齐后，用户实际模拟反馈“效果很好”。该反馈不覆盖全部游戏流程、网络和低帧率场景。

目标运行时CMC/Ragdoll代码没有因这次资产迁移增加PhysicsControl依赖，相关职责仍见主责 [ragdoll.md](../../ragdoll.md)。

## 差异和处理结果

| 项目 | 迁移前目标 | 源 / 最终目标 |
| --- | --- | --- |
| body / primitives | 22 / 18胶囊+4盒 | 23 / 19胶囊+4盒，补入spine_01 |
| constraints | 23，包含3条交叉约束 | 22，完整源拓扑 |
| 禁用碰撞对 / 可碰撞组合 | 227 / 4 | 68 / 185 |
| PA solver | CullDistance=1、非线性joint选项 | CullDistance=3、UseLinearJointSolver=true |
| PCA PhysicsAsset | 旧PA_Mannequin | PA_Mannequin_PC |
| 子步进 | false、最大6步 | true、最大16步 |
| AsyncFixedTimeStepSize | 约0.0333333 | 0.016667 |

`N*(N-1)/2 - DisabledPairs`在本例给出185/4，且编辑器显示实际数值相符；这个算式不替代其他特殊过滤/运行状态的检查。

源/目标骨名能一一匹配，参考姿势与长度却不同。直接套用源Pos2到Manny时最大锚点偏差约9.425cm，出现在spine_05链；hand约4.90cm、calf约4.29cm、spine_01约3.14cm。此次使用单位child_basis，保留源Pos1/子轴，以目标参考姿势重算Pos2/父轴，保持源关节相对角度。保留全部源形状尺寸、BodyInstance、Constraint Profile，未引入额外“防滑阻尼”补偿。

## 特殊默认值必须保留

- 材质Friction=1.75、StaticFriction=1；摩擦/反弹均Multiply且覆盖，Restitution=0。
- Density=1、RaiseMassToPower=0.75；SleepLinearVelocityThreshold=1、Angular=0.05、Counter=4。
- `neck_02/head`在源中没有显式BodySetup.PhysMaterial，其余21体有PM。中间候选曾统一赋PM，最终回读时发现并恢复这两个null例外。维护脚本现从快照一开始就保留。
- neck_02默认MassInKgOverride字段100，但bOverrideMass=false；不能将100当实际覆盖质量。其余覆盖值以完整[基线](case-data/baseline.json)为准，不另编一个误导性的总质量。
- PA solver Position/Velocity/Projection=6/1/1、CullDistance=3、MaxDepenetrationVelocity=0、FixedTimeStep=0、UseLinearJointSolver=true、UseManifolds=false、SolverType=World。其设置用途与World实际solver区分见工作流。

## PCA与编辑器设置

两边PCA authored Setup、Sets、InitialUpdates和 `kinematic/physicalAnimation/ragdoll` Profiles逐项相同，仅原PhysicsAsset引用不同。更新目标引用后 `IsCompilationNeeded=false`。

关键Profile片段如下，完整字段/掩码以baseline.json为准：

| Profile | 内容 |
| --- | --- |
| kinematic | 所有Controls禁用，BodyModifiers设Kinematic |
| physicalAnimation | WorldSpace线/角Strength=3；ParentSpace角Strength=15、DampingRatio=3；WorldSpace_Feet线/角Strength=10；Bodies模拟、GravityMultiplier=0 |
| ragdoll | WorldSpace禁用；ParentSpace角Strength=10、DampingRatio=3，仍启用；Bodies模拟、GravityMultiplier=1 |

两边鼠标弹簧线阻尼/刚度200/750、角阻尼/刚度500/1500、InterpolationSpeed=50；PhysicsBlend=1、UpdateJointsFromAnimation=false、GravScale=1、无GravityOverride、MaxFPS=-1。有效PhysicsSettings完整回读一致，1208个同名 `p.*` CVar值一致；不是只比较了配置文件中显式写出的几行。

最终PA依赖只有目标Manny预览Mesh和新PM；临时源包和候选Content已清理。原PA_Mannequin未作为本次改写对象。

## 原脚本如何归档与精炼

原始会话脚本以 `.py.txt` 归档在 [case-scripts](case-scripts)，只用于追溯，不直接执行。它们是最终留存版本，不能恢复每次中间编辑。hash清单在baseline.json。

| 原脚本 | 当次用途 | 维护入口替代 |
| --- | --- | --- |
| mcp_client.py | 双端口初始化与临时工具调用 | scripts/mcp_client.py + run_job.py |
| register_tools.py | 当次固定阶段Toolset | unreal_worker.py的稳定V1 bootstrap |
| inspect_live.py / inspect_api.py | API探测、初始配置与T3D导出 | snapshot；原inspect_live曾因protected API得到空数组，不作为完整体数据来源 |
| prepare_source.py / prepare_target.py | 材质、参考姿势、dirty、备份/引用 | snapshot / stage |
| stage_candidate.py | 源包暂存、候选复制、native预览Meshsetter | stage |
| adapt_candidate.py | 本例单位basis的Pos2/父轴计算 | plan / adapt，增加显式改名/basis/统一缩放边界 |
| verify_target.py | 全字段回读、PCA编译与设置检查 | verify |
| apply_target.py | 备份hash、卸载后替换、PCA引用和CDO | commit，修正unload返回元组真假问题并记录多资产部分提交状态 |
| cleanup_source.py | 材质null修正、依赖核对和删除临时包 | adapt保留null；cleanup/discard按拥有关系和引用拓扑清理 |

原脚本中 `apply_target.py` 会把unload结果元组整体当布尔，`cleanup_source.py`还承担材质修正，且阶段文件曾被重写；这些都不应原样推广。维护版本把职责固定、输入参数化，plan/review绑定摘要，候选适配可重复执行不累计变换。

## 新入口验证记录

维护版本通过当前两个编辑器实际执行 snapshot → plan → stage → adapt → verify → discard，使用独立作业 `skill-readonly-validation-20261125`。候选为23体/22约束，源剪贴板68禁用对、预期185组合，实际回读锚点误差在浮点数误差范围内；候选和暂存源包已清理，未重新commit正式PA/PCA/Config。

随后 `skill-final-validation-20261125` 又完成了增加数组顺序/BodySetup可编辑字段后的真实snapshot和离线comparison/plan：拓扑、PhysicsSettings和p.*对照无差异；源编辑器此后退出，stage在source连接复核处停止，没有创建新候选。这轮没有重复宣称完成新的正式落盘或动态验收。

验证中修正了骨名read-only setter和Python UClass热重载导致Invalid Toolset Class的问题。不同骨名/非单位basis/统一缩放的代码与数学边界已明确，但本次实测骨架仍为同名UEFN→Manny；不能据此声称已对所有不同骨架完成动态验收。正式commit的新封装未在当前已被PCA引用的PA上强行执行，保留referencer停止条件。

另外在23个真实刚体几何的独立Struct副本上执行了30°局部旋转与1.1倍统一缩放，验证球/盒/胶囊转换所用Python API能执行；没有保存或改变正式几何。这是转换接口验证，不是该体型/轴映射的动态适配验收。
